# 《寻宝东莞》演示演讲稿

大家好！欢迎来到《寻宝东莞》——一款手柄操控的 Canvas 寻宝小游戏。

**【开场·30秒】**
三星堆特展正在东莞博物馆火热举行，可就在开幕前夜——镇馆之宝"青铜纵目面具"神秘碎裂，灵韵散落全城！现在，请大家跟随舞狮机器人特派员，踏上寻宝之旅：松山湖、可园、虎门炮台、南社古村、东莞国贸……每收集一件碎片，就能解锁一段它背后的文化故事。

**【玩法·现场演示】**
大家看，用手柄左摇杆操控角色，碰撞宝物即可收集——手柄会"嗡"地一震，金色粒子飞溅，弹出宝物档案。比如这一件"纵目之瞳"，正是面具上凸起的眼睛；在虎门炮台找到的"青铜战戈"，呼应着海防历史的厚重。集齐一关三件，即可解锁下一座地标。

**【高潮·终极合成】**
当五关十五件碎片全部集齐，博物馆终极关卡开启——全场变暗、金青双色粒子环绕，完整青铜纵目面具破土复苏，手柄传来两秒的最强震动！这一刻，文物在指尖"重生"。

**【技术·一句话】**
整个游戏零框架、零物理引擎，纯 HTML + JavaScript + Canvas 手写实现，所有美术素材均由 AI 生成抠图，从场景到宝物再到角色动画，一个人、一套工具，几天完成。

**【结尾】**
科技让文物活起来，游戏让文化传下去。《寻宝东莞》，期待您的体验！谢谢大家！
